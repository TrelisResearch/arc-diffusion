# ARC Diffusion
**A diffusion approach to solving ARC.**

Quickstart:
To get started on Runpod, you can avail of this one-click affiliate [template](https://console.runpod.io/deploy?template=4yg1dndu1e&ref=jmfkcdio).

Running scripts:
Install with
```bash
uv sync
```
and see how to run scripts by running:
```bash
uv run script.py -h
```
